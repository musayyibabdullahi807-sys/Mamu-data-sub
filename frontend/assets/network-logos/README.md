# Network logo assets

These provider logo files are included for network identification in the data and airtime selectors.

Source: [Nigerian Utility Logos collection](https://github.com/josephajibodu/utility-providers-assets/tree/main/network-providers)

Files: `mtn.svg`, `airtel.svg`, `glo.svg`, and `9mobile.svg`. The source repository states that the logos remain the property of their respective trademark owners, and that use should follow each brand’s usage guidelines.
